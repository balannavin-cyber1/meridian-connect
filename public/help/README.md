# public/help: content for the Marketview `/help` route

**This folder is data. The page that renders it is code.** Every word and picture on `/help` comes from here, and the page adds none of its own.

## What is in this folder

| Path | What it is |
|---|---|
| `manual.json` | The Marketview user manual, pre-rendered. It is generated by `build_help_pack.py` (MERIDIAN docs, `docs/marketview_manual/`) from `marketview_user_manual.md`. **Do not edit it by hand.** Regenerate it and replace the file. |
| `shots/*.jpg` | Real screenshots of the live board. Each one is stamped in `manual.json` with symbol, date, IST time and board bundle. Do not crop, annotate or recolour them. |

## The shape of `manual.json`

```
{
  title, manual_version, board_bundle, source_sha256,
  preface_html,
  parts: [
    { id, title, intro_html,
      shots:    [ { file, caption, symbol, date, time_ist, board_bundle } ],
      sections: [ { id, title, html, shots: [ ... same shape ... ] } ] }
  ]
}
```

- **`file` paths are relative to the site base**, for example `help/shots/nifty_0952_pin.jpg`. Resolve them against `import.meta.env.BASE_URL`, which is `/` live and `/staging/` on staging.
- **`*_html` fields are HTML generated from our own Markdown.** They contain only these elements: `p`, `ul`, `ol`, `li`, `strong`, `em`, `code`, `table`, `thead`, `tbody`, `tr`, `th`, `td` and `blockquote`. No scripts or links come from outside.
- **Section `id`s are stable anchors**, for example `s2-3` is §2.3 NET Γ and `s3-5` is §3.5 Flows. They can be deep-linked as `/help#s3-5`.

## How an update happens

1. The manual changes.
2. `python3 build_help_pack.py <meridian-connect root>` is run.
3. The new `manual.json` and any new shots are committed here.

**No page code changes when the content changes.**
